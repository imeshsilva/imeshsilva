### 🔐 AI-Powered Malware Sandbox Analyst

**Kingston University — Final-Year Project**

An automated malware analysis pipeline combining sandbox analysis, workflow automation, and AI-generated threat intelligence.

- Integrated Cuckoo Sandbox, n8n, and Google Gemini to convert sandbox results into readable threat reports.
- Deployed an isolated Windows virtual machine environment for analyzing malware behavior.
- Used custom network routing to observe process activity and command-and-control traffic.
- Generated structured reports containing threat verdicts, risk levels, MITRE ATT&CK mappings, and mitigation recommendations.
- Automated file ingestion, sandbox API communication, JSON processing, and result delivery using n8n and WireGuard VPN.
- Implemented Uptime Kuma monitoring, Slack alerts, and GitHub Actions for workflow backups.

**Technologies:** Cuckoo Sandbox · n8n · Google Gemini · DigitalOcean · WireGuard · Uptime Kuma · GitHub Actions
